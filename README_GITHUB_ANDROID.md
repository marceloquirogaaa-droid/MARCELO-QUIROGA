# GymFlow - compilación automática

Este repositorio está preparado para compilar el APK Android automáticamente con GitHub Actions.

## Automático
Cada push a `main` ejecuta **Build GymFlow APK**.

## Manual
GitHub > Actions > Build GymFlow APK > Run workflow.

Al finalizar, abrir el workflow y descargar el artifact **GymFlow-APK**. Dentro está `GymFlow-debug.apk`.

No hace falta Android Studio para compilar en GitHub.
